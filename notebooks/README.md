# Notebooks

Notebook 仅用于探索、诊断和结果展示。可复用的数据处理、建模、评价和策略逻辑应逐步迁移到 `src/credit_risk/`。

打开 Notebook 后应选择项目根目录 `.venv` 中的 Python 3.11 解释器。不要使用 Conda `base` 或其他项目环境，否则可能缺少 `requirements.txt` 中的依赖。

计划按以下顺序组织：

- `01_data_audit.ipynb`: verifies the downloaded workbook and displays the reproducible quality audit
- `02_eda.ipynb`
- `03_model_experiments.ipynb`
